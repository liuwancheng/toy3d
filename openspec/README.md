# OpenSpec 的使用边界

本目录保留既有 specs/changes，供用户明确选择 OpenSpec 时使用或追溯历史。日常开发入口是 ../document/index.md 与根 AGENTS.md，本目录旧设计、任务勾选和归档状态不构成默认当前规范。

仓库 openspec-* skills 关闭隐式触发；只有用户显式调用对应 skill 或明确要求 OpenSpec 工作流时使用。普通探索、修复、设计或功能开发不需要新建 change、补旧任务、同步/归档后才继续。

长期知识直接更新功能文档；不要再在此复制一份新的产品规范。使用旧 change 时先对照当前接口/测试与功能文档，明确此次变更范围，避免把历史施工约束重新带回日常流程。
