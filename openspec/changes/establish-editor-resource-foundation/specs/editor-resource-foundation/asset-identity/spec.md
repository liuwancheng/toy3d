# Spec Delta

## Purpose

定义编辑器资源、导入子资源与引用的持久化身份，使模型、动画、碰撞和场景能跨文件移动、重新导入及运行时重建保持可检查的依赖关系，而不依靠宿主路径或进程内指针。

## ADDED Requirements

### Requirement: Asset 身份与文件位置分离
每个持久化资源 MUST具有稳定 Asset 身份；资源索引 MUST将该身份解析为受控虚拟路径及资源类型。`engine/asset/` 是引擎现有资产目录，其下的子目录由使用者自由组织；资源类型 MUST由文件内类型身份识别，不得从文件夹名或固定目录层级推断。移动或重命名项目文件 MUST不改变资源身份；重复身份、同一身份映射冲突及不合法虚拟路径 MUST返回明确错误。宿主物理路径、`shared_ptr` 地址和渲染资源指针 MUST不成为文件内资源身份。

#### Scenario: 文件改名
- **WHEN** 资源文件在项目命名空间内改名且保留其 Asset 身份
- **THEN** 既有场景和动画引用 MUST通过该身份解析到新路径

#### Scenario: 任意资产目录
- **WHEN** 同一类型的两个资源被放入 `engine/asset/` 下不同的用户自定子目录
- **THEN** 索引 MUST根据各自文件的身份和类型识别它们，不要求目录名为 `mesh` 或其他预设分类

#### Scenario: 身份冲突
- **WHEN** 两个资源文件声明同一 Asset 身份
- **THEN** 索引 MUST报告冲突并拒绝任选其中一个作为权威资源

### Requirement: 外部资源与导入子资源可区分
持久化引用 MUST能区分顶级 Asset 与该 Asset 内的子资源，并保存预期资源类型。模型导入产生的 mesh、skeleton、animation 等子资源 MUST有不依赖数组下标或当前遍历顺序的稳定子资源身份。重新导入无法匹配旧子资源时 MUST报告失配，不得把引用悄悄改绑到同一位置的新内容。

#### Scenario: 模型节点重排
- **WHEN** 源模型重导入后 mesh 顺序改变而同一 mesh 的稳定子资源身份仍可匹配
- **THEN** 指向该 mesh 的场景引用 MUST保持有效

#### Scenario: 子资源消失
- **WHEN** 被动画或场景引用的子资源在重导入后消失
- **THEN** 引用 MUST保持其原身份并报告缺失，不得按索引指向另一子资源

### Requirement: 引用解析不取得领域对象所有权
资源引用 MUST先表达 Asset 身份、可选子资源身份和期望类型；由资源领域解析器按当前项目索引和加载策略取得运行时对象。反射及通用编解码层 MUST不直接加载 `Texture`、`StaticMesh`、物理对象或 RHI 对象，也不得让离线工具为解析身份而依赖 runtime。

#### Scenario: 类型不匹配
- **WHEN** 动画文档的 skeleton 引用解析到纹理资源
- **THEN** 解析 MUST返回带引用位置和预期/实际类型的错误，不得进行无检查转换

### Requirement: 依赖可枚举且循环有明确错误
Asset 文件索引 MUST能枚举其直接外部资源依赖，供编辑器、Cook 和删除检查使用，而无需解码全部类型数据。解析器 MUST检测会导致加载无法完成的依赖循环，并报告循环路径；允许的延迟或弱引用 MUST由领域 schema 显式声明，不能由通用解析器猜测。

#### Scenario: 循环的强依赖
- **WHEN** 资源 A 强依赖 B 且 B 强依赖 A，二者均要求对方先完成加载
- **THEN** 加载 MUST失败并报告 A→B→A，不能递归直至栈耗尽
