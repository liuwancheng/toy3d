# Spec Delta

## Purpose

定义类型化资源数据供未来编辑器检查、修改、撤销和预览的无界面行为，使通用属性操作能复用反射描述，同时让各资源领域继续掌握验证、重建与运行时发布策略。

## ADDED Requirements

### Requirement: 属性路径可定位复合资源数据
编辑操作 MUST能定位嵌套结构、数组元素及受控变体分支，并依据同一 schema 取得值类型、编辑用途和提示。可重排的作者创建集合 MUST使用稳定元素身份维持选择、撤销及跨引用定位；仅表示顺序的数组可使用索引，但顺序变化 MUST不被误认为元素身份不变。

#### Scenario: 选择动画事件
- **WHEN** 用户选中某个动画事件后在其前面插入另一事件
- **THEN** 原事件的编辑选择与撤销目标 MUST仍指向同一事件

### Requirement: 修改形成可撤销的完整事务
每次提交 MUST先完成类型、属性用途、资源引用及领域约束验证，然后以一个可撤销事务发布旧值、新值和受影响资源身份。验证或应用失败 MUST不改变类型化资源数据、不新增撤销记录且不通知预览。复合不变量 MUST允许多个字段作为一个值或一个事务共同提交。

#### Scenario: 相机参数联合修改
- **WHEN** 用户同时调整 near/far，单独设置中间值会违反 near < far
- **THEN** 编辑器 MUST能一次验证并提交最终有效组合，撤销时也 MUST恢复整个组合

#### Scenario: 只读属性修改
- **WHEN** 编辑请求指向只读或不可编辑属性
- **THEN** 请求 MUST失败且资源数据、撤销栈和预览状态 MUST不变

### Requirement: 脏状态与保存结果一致
成功编辑 MUST使资源进入待保存状态；只有目标 Asset 文件成功发布后才能清除对应待保存状态。失败保存、失败迁移或重导入冲突 MUST保留可恢复的编辑状态，并返回包含资源/属性位置与原因的错误，由调用方决定记录日志或显示 Dialog。

#### Scenario: 保存失败
- **WHEN** 资源数据已编辑而文件系统原子替换失败
- **THEN** 编辑值和撤销记录 MUST保留，资源 MUST继续显示未保存

### Requirement: 预览更新由领域适配器处理
编辑事务 MUST向相关领域提供已验证的变更通知和变更类别；反射和通用编辑层 MUST不直接创建或修改 RHI、物理后端、ShaderMap、SceneProxy 或 `Actor` 生命周期状态。预览适配器接入时 MUST区分可原位更新的属性与需要重新导入、重新 Cook 或完整候选 replacement 的结构变化；候选失败 MUST保留旧预览。本 change 用假适配器验证通知与失败边界，不交付生产预览器。

#### Scenario: 模型导入设置修改
- **WHEN** 用户修改模型坐标转换或法线生成设置
- **THEN** 编辑事务 MUST标记需重新导入的变更；接入的领域适配器 MUST保持旧可用预览至新结果完整验证后

#### Scenario: 材质动态参数修改
- **WHEN** 用户调整已登记 Shader `Properties` 中的普通动态数值
- **THEN** 后续材质适配器 MUST经现有 Material setter 与 RenderCommand 边界应用；本 change 的假适配器 MUST证明通用编辑层不会直接写 RenderProxy
